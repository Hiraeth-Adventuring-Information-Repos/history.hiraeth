1. **Identify bottleneck**: The initial data render time is delayed because the `fetch` for the six JSON era data files only starts when the JavaScript execution begins in `initializeTimeline()`. This means the browser has to wait for HTML parsing, Tailwind loading, and other synchronous tasks before it even starts downloading the data required for rendering.
2. **Implement optimization**: Add `<link rel="preload" as="fetch" crossorigin="anonymous">` tags in the `<head>` of `index.html` for all six era JSON files (`modern-era.json`, `unification-age.json`, etc.). This tells the browser to start fetching these critical resources immediately, concurrently with HTML parsing, significantly improving the initial data render time.
